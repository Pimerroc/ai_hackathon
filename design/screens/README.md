## Договорённости

- **В sidebar только «Главная» и «Альфа-Инсайт».** Счета, платежи и другие разделы Альфа-Бизнеса не рисуем и не реализуем (review krchvl в !1).
- **Ровно 6 блоков** в карточке инсайта. Уверенность — в шапке и блоке 3, ограничения — в блоке 6.
- **Чат и trace — немодальная правая панель** 460px на desktop: инсайт остаётся видимым. На mobile — лист снизу.
- **Риск — оранжевый `color.risk`**, фирменный красный — только у позиции Альфа-Банка и основной кнопки.
- Состояния `hover / focus / pressed` в статике зафиксированы классами `.is-hover`, `.is-focus`, `.is-active`.

## Плейсхолдеры: заменить до демо

- Компании, люди, суммы и новости вымышлены. Финальные данные придут из seed (#31).
- **Цитаты «Позиции Альфа-Банка» — заглушки.** В демо нужны дословные цитаты из 9 PDF с реальной страницей (#23).
- Логотип — плейсхолдер (красный квадрат). Реальные логотипы в макетах не используем.

## Обновить PNG

```bash
python design/screens/export_png.py              # все экраны
python design/screens/export_png.py 04-insight   # один экран
```

Нужен Chrome или Edge (путь можно задать через `CHROME=...`). Mobile снимается через `08-mobile.html`: headless Chrome не делает окно уже ~500px.
