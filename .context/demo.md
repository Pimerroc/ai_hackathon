# Демо и сдача

## Формат

- ZIP-архив, не hosted demo.
- Проверяющий запускает локально:
  ```bash
  cp .env.example .env
  docker compose up --build
  ```
- Свой ключ — в `.env`; без ключа работает `DEMO_MODE=1`.
- 5 минут на защиту + ответы.

## Три сценария

### 1. Металлургический экспортёр

- Компания с кредитами, валютной выручкой и экспортом.
- Новость: изменение ключевой ставки / курса / пошлин.
- Показываем: риск долговой нагрузки, возможность хеджирования, позиция Альфа-Банка, действие.
- Trace: профиль → новость → аналитика банка → критик → инсайт.

### 2. Ритейлер-импортёр

- Компания с импортом, логистикой и контрагентами.
- Новость: логистический сбой / курс / ограничения.
- Показываем: риск цепочки поставок, альтернативный маршрут, возможность.
- Чат: «Что будет с маржой, если курс вырастет на 10%?» — ответ с цитатами.

### 3. Строительная группа

- Группа компаний, гарантии, факторинг.
- Новость о контрагенте/партнёре.
- Показываем: косвенный риск через граф, почему это важно для группы.
- Источники и confidence.

## Сценарий демо (5 минут)

1. **0:00–0:30** — проблема: новостной шум, нет контекста, AI-галлюцинации.
2. **0:30–1:00** — вход в Альфа-Бизнес, карточка «Что влияет на бизнес».
3. **1:00–2:00** — смена клиента: лента меняется; почему в ленте.
4. **2:00–3:00** — инсайт из 6 блоков; бейджи fact/bank/AI; цитата Альфа-Банка.
5. **3:00–3:45** — чат: уточняющий вопрос, ответ с источниками.
6. **3:45–4:15** — trace: шаги, tools, модель, токены.
7. **4:15–4:45** — feedback и живая новость.
8. **4:45–5:00** — архитектура, метрики, безопасность, масштабирование.

## Fallback

- `DEMO_MODE=1` без ключа.
- Precomputed insights.
- Backup video.
- Backup screenshots.
- Если LLM недоступен — баннер и демо-данные, не падение.
- Если внешние источники недоступны — fixture news.

## Что показывать

- Персонализация, а не общая лента.
- 6 вопросов кейса.
- Точная цитата банка.
- Разделение факта/мнения/AI.
- Multi-step агент и trace.
- Устойчивость к неполным данным.
- Метрики качества.
- Масштабирование и безопасность.

## Что не показывать

- Внутренние prompt’ы.
- Ключи и `.env`.
- Сырые логи.
- Нестабильные P1-функции.
- Долгие live-вызовы без таймаута.

## Submission checklist

- [ ] ZIP собран, checksum совпадает.
- [ ] В ZIP нет `.env`, ключей, `.git`, node_modules, .venv, кэшей, логов.
- [ ] `repo.bundle` приложен.
- [ ] README: запуск, env, demo-аккаунты, troubleshooting.
- [ ] `.env.example` без ключа.
- [ ] `docker compose up --build` на чистой машине.
- [ ] `make seed`, `make smoke`, 3 demo-сценария.
- [ ] OpenAPI, architecture, THIRD_PARTY, lock-файлы.
- [ ] Demo video и screenshots.
- [ ] Тег `v1.0.0`, GitLab Release, `COMMIT_SHA`.
- [ ] Проверено, что в ZIP нет `sk-`.
- [ ] Архив отправлен, SHA и время записаны.
